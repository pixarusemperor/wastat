# Issue Tracker

Issues for this repository are tracked in **GitHub Issues**.

- Repo: `pixarusemperor/wastat`
- CLI: `gh` (GitHub CLI)
- Auth: already authenticated (`gh auth status`)

## Commands

Create an issue:

```
gh issue create --title "..." --body "..."
```

List issues:

```
gh issue list
```

View an issue:

```
gh issue view <number>
```
