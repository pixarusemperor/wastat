# Issue Tracker

Issues for this repository are tracked in **GitHub Issues**.

- Repo: `pixarusemperor/wastat`
- CLI: `gh` (GitHub CLI)
- Auth: authenticated (`gh auth status`)

## Commands

Create an issue:

```bash
gh issue create --title "..." --body "..."
```

List open issues:

```bash
gh issue list
```

View an issue:

```bash
gh issue view <number>
```

Add labels:

```bash
gh issue edit <number> --add-label "ready-for-agent"
```
